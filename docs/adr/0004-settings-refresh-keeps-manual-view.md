# 设置刷新不重置手动缩放与平移

0.1.11 之前，`refresh()` 在「渲染签名没变」的短路分支里无条件调用 `applyFit()`，而设置面板每次改控件
都会对全部卡片调 `refresh()`。结果是：用户把一张大图放大、拖到某个局部后，只要改 PNG 分辨率、界面语言
或工具条显示方式，所有图都会弹回自适应位置。

现在把三类因素拆开记录：

- **几何签名**（主题身份、布局引擎、ELK 选项、判断节点形状、plain 的明暗）：变了才重建卡片，手动视角
  随之作废；
- **适配输入**（自适应方式、最大放大倍率、最大高度）：变了重新 `applyFit()`；
- **其它**（语言、图片化开关、工具条模式、PNG 参数、主题名称）：可以重建或只同步界面，但保留视角。

语言与图片化仍在签名里、会走整卡重建；重建后按旧的自然尺寸把 `{zoom, tx, ty}` 放回去
（`restoreManualView()`），只有新图尺寸确实变了才退回自适应。

## Consequences

- 「复位缩放」命令、改自适应参数、改主题变量仍会重置视角 —— 这些是有意保留的出口。
- 窗口高度单独变化不会触发重新适配（`ResizeObserver` 只看宽度），是已知边界。
- 新增会影响几何的设置项时必须同步加进 `geometry` 数组；只影响界面或导出的项**不要**加进重渲染签名，
  否则用户视角会被无谓地重置（ADR 0002 的教学标签同步同样走短路分支）。
