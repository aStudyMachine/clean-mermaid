# 双击画布 = 展开查看，复位缩放让位

自 0.1.0 起，双击图表就是「复位缩放」（`doubleClickReset`，默认开启）。0.1.9 起双击改成**
展开查看**，与卡片工具条上的展开按钮打开同一个窗口。理由是手势要唯一对应一个结果：
曾经考虑过两段式（图被手动缩放/平移过时双击复位，否则展开），但那样同一个手势会依据一个
用户看不见的内部状态给出两种行为，学不会也教不了；而「复位」本身已有两个可见入口
（`⋯` 菜单的「重置缩放」、手动缩放后才出现的右下角缩放徽标），不依赖双击。

代价是改了已发布的手势契约，因此旧开关升级成三选枚举 `doubleClickAction`
（`viewer` 默认 / `reset` / `off`）：想保住旧习惯的用户在设置里能改回来，此前把双击复位
关掉的配置迁移为 `off`（保留「双击别做任何事」的本意）。

## Consequences

- 双击不再能复位；`README` 与 `CONTRIBUTING` 的手势表、验收清单都得跟着改。
- 迁移只发生在 `migrateSettings()`，旧键 `doubleClickReset` 会被删除并落盘，不要让它在
  `data.json` 里长期残留。
- 顺带把入口文案从「全屏打开」改成「展开图表」：那个窗口是占视口 92% × 88% 的浮层，
  不是系统级全屏，旧措辞名不副实（术语见 `GLOSSARY.md`）。
