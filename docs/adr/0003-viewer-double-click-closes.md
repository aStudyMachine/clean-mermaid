# 查看器内双击 = 关闭窗口

展开查看窗口里的双击在 0.1.8 是「重新开启自适应」（`fit()`），0.1.9 改成**关闭窗口**：一次双击
就能开、再双击就能关，鼠标用户不必去够 `Esc` 或右上角的叉。代价是「自适应」少一个手势入口 ——
它仍有工具条按钮和 `0` 键两条路，而「关窗」此前除了 `Esc` 和叉没有鼠标入口，补上这个净值是正的。

只对查看器内任意位置生效（含图像本身），**不区分窗口是怎么打开的**：从卡片双击进来和从 `⤢` 进来
行为一致。按打开方式分派是 0001 已经否掉的毛病 —— 同一手势给出两种结果。

## Consequences

- 拖拽平移后松手容易连出第二次按下，所以按画布上累计位移设阈值（`DRAG_CLICK_TOLERANCE = 4px`），
  超过就当拖拽，不关窗。
- 工具条区域不在 `stage` 上，双击工具条不会关窗（避免点按钮时的连击误触）。
- 重新把双击接回 `fit()`、或按「拖过才关」之类的两段式改，先回来读这一页。
