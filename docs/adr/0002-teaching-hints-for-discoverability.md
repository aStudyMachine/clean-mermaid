# 发现性靠「一次性提示 + 用到即撤的标签」，不靠常驻控件

展开查看这个能力从 0.1.x 就存在，但默认工具条是悬停才淡入（`toolbarMode: "hover"`），
画布本身也没有任何可交互暗示，于是对绝大多数用户等于不存在。0.1.9 加了两层教学：

1. **一次性提示条**：本机第一次渲染出卡片时弹一条 Notice，说「双击图表即可展开查看」。
2. **教学标签**：还没展开过任何图表之前，工具条左侧显示「双击展开」（与工具条同时淡入，
   `pointer-events: none` 不挡拖拽和双击）；任意图表展开过一次，所有卡片上的标签一并撤掉。

两层标记都存在 `localStorage`（`src/hints.ts`），**不进** `data.json`：它们是教学状态而非用户配置，
混进 settings 会被「恢复默认设置」连带清掉，也会在设置面板里多出一个不属于设置的对象。

## Considered Options

- **首屏浮层掩盖图表**（点击即开、之后永不再现）：与一次性提示条收益重叠，还要处理多图笔记里
  「哪一张」的歧义，砍掉。
- **让工具条常显**：能解决看见问题，但等于让每张图常驻两个按钮，破坏卡片留白；留着作为用户自选
  设置（`toolbarMode: "always"`）更合适。
- **命令面板加「展开当前图表」**：插件没有「当前图表」这个概念，多图笔记里语义是坏的，不做。

## Consequences

- 标签的显示条件是「还没展开过 + 双击确实绑在展开上」，两个条件都要判：把 `doubleClickAction`
  改成别的之后标签会变成谎话，必须一起消失。
- 用户清掉本机存储（或换机器）会再看一遍提示，属于可接受的重复成本。
